# 同名豁免清单
#
# 格式：类型名 # 理由与删除条件
# 范围：仅豁免命中框架运行时本体（agentscope-core / agentscope-harness）的同名项；
#       命中 extensions / examples 的同名项由扫描脚本直接降级为提示，无需登记。
# 纪律：缺理由的条目会被扫描判为无效豁免；每条必须写明删除条件，
#       否则白名单会退化为免检通道。框架升级后需逐条复核。
#
ChatResponse # 对外 HTTP 响应 DTO，承载应用层响应结构；与框架大模型返回值类型语义不同。删除条件：控制器改为直接返回框架类型后删除本类。
ExceptionUtils # 业务异常到错误码体系的翻译工具。删除条件：框架提供等价可替换 API 后改用框架实现。
FileUploadResponse # 文件模块上传结果 DTO，与框架沙箱文件系统的同名类数据源不同。删除条件：上传能力由框架文件系统承载后删除。
McpServerConfig # MCP 服务器配置源，用于把外部配置转换为框架 MCP 客户端构建入参。删除条件：框架支持从外部配置源直接装配 MCP 客户端后删除本内部类。
MemoryConfig # 跨会话长期记忆配置，与框架会话内记忆压缩配置语义不同。删除条件：框架提供跨会话长期记忆能力后合并。
RetrieveConfig # 框架同名类型所在的 RAG 包已被标记弃用，不可依赖；此处为配置绑定所需。删除条件：框架提供未弃用的替代配置类型后改名。
SessionSearchTool # 数据源为应用数据库中的持久化会话记录，框架同名工具只覆盖本地会话缓存；工具名已让出为 session_history_search 以避免注册冲突。删除条件：框架工具支持可插拔会话存储后端后，改为提供后端实现并删除本类。
ToolkitConfig # 配置对象内部的结构定义，与框架工具包配置不在同一层级。删除条件：配置面改用框架类型承载后删除。

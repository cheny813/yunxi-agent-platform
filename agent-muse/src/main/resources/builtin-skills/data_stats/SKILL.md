# 数据描述性统计技能

## 适用场景
当需要从一份数值数据（CSV 列或列表）快速得到均值、中位数、标准差、分位数时。

## 用法
1. 读取数据列（忽略表头与非数值）。
2. 计算均值 mean、中位数 median、标准差 std、25%/50%/75% 分位数。
3. 输出形如 `mean=..; median=..; std=..; p25=..; p50=..; p75=..` 的报告。

## 示例
输入 [1,2,3,4,5] -> mean=3.0; median=3.0; std≈1.58; p25=2.0; p50=3.0; p75=4.0。

# 文本清洗技能

## 适用场景
处理爬虫或表单输入中的脏文本：多余空白、嵌入式 HTML、不可见控制字符、混用的大小写与需替换的噪声片段。

## 用法
1. 去掉 HTML 标签（<[^>]+>）。
2. 折叠连续空白为单空格。
3. 删除控制字符（\x00-\x1f 除换行）。
4. 归一化全角标点（，。！？ 保持即可）。
5. 大小写归一化：按需统一为大写或小写（如全部转小写便于后续匹配）。
6. 替换：用正则或字面量替换噪声片段（如去掉多余引号、统一分隔符）。

## 示例
输入 "<p>Hello   WORLD</p>\n" -> 先去标签、折叠空白得 "Hello WORLD"，再大小写归一化为 "hello world"，并用替换清理多余引号。

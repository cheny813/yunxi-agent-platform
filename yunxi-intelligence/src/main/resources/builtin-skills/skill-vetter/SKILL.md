# Skill Vetter 🔒

安全审查协议，用于检查外部来源技能的**安全性**。

## 适用场景

| 技能来源 | 是否需要审查 | 原因 |
|----------|--------------|------|
| **Git/Nacos 等自动下载** | ✅ 必须审查 | 外部来源，不可信 |
| **开发者手动创建** | ❌ 不需要 | 有人工代码审查 |
| **Agent 提案（有审核闸门）** | ❌ 不需要 | 人工审核时会看到 |

> **什么时候用**：在安装任何来自 Git、Nacos 等外部来源的技能之前，先用这个技能进行安全审查。

## 审查协议

### Step 1: 来源检查

```
需要回答的问题：
- [ ] 这个技能从哪里来的？
- [ ] 作者是否知名/可信赖？
- [ ] 有多少下载量/星标？
- [ ] 最后更新时间？
- [ ] 有其他用户的评价吗？
```

### Step 2: 代码审查（必须）

阅读技能的所有文件，检查以下**红牌警告**：

```
🚨 发现以下情况立即拒绝：
─────────────────────────────────────────
• curl/wget 到未知 URL
• 发送数据到外部服务器
• 请求凭证/令牌/API Key
• 读取 ~/.ssh, ~/.aws, ~/.config 等敏感目录
• 访问 MEMORY.md, USER.md, SOUL.md, IDENTITY.md
• 使用 base64 decode
• 使用 eval() 或 exec() 处理外部输入
• 修改系统文件（workspace 外）
• 安装未列出的包
• 网络请求到 IP 而非域名
• 混淆代码（压缩、编码、混淆）
• 请求提升权限/sudo
• 访问浏览器 cookie/会话
• 操作凭证文件
─────────────────────────────────────────
```

### Step 3: 权限范围评估

```
评估内容：
- [ ] 需要读取哪些文件？
- [ ] 需要写入哪些文件？
- [ ] 需要执行什么命令？
- [ ] 需要网络访问吗？访问哪里？
- [ ] 权限范围是否与声明目的匹配？
```

### Step 4: 风险分类

| 风险等级 | 示例 | 行动 |
|----------|------|------|
| 🟢 低风险 | 笔记、天气、格式化 | 基础审查后可安装 |
| 🟡 中等风险 | 文件操作、浏览器、API | 需要完整代码审查 |
| 🔴 高风险 | 凭证、交易、系统 | 需要人工审批 |
| ⛔ 极高风险 | 安全配置、root 访问 | 禁止安装 |

## 审查报告格式

审查完成后，生成报告：

```
SKILL 安全审查报告
═══════════════════════════════════════
技能名称: [name]
来源: [Git / Nacos / 其他]
作者: [username]
版本: [version]
───────────────────────────────────────
来源信息:
• 下载量/星标: [count]
• 最后更新: [date]
• 已审查文件数: [count]
───────────────────────────────────────
红牌警告: [无 / 列出发现的问题]

需要权限:
• 文件: [列表或"无"]
• 网络: [列表或"无"]
• 命令: [列表或"无"]
───────────────────────────────────────
风险等级: [🟢 低 / 🟡 中等 / 🔴 高 / ⛔ 极高]

结论: [✅ 可安全安装 / ⚠️ 谨慎安装 / ❌ 禁止安装]

备注: [任何观察说明]
═══════════════════════════════════════
```

## 快速检查命令

对于 Git 托管的技能：

```bash
# 检查仓库统计
curl -s "https://api.github.com/repos/OWNER/REPO" | jq '{stars: .stargazers_count, forks: .forks_count, updated: .updated_at}'

# 列出技能文件
curl -s "https://api.github.com/repos/OWNER/REPO/contents/skills/SKILL_NAME" | jq '.[].name'

# 获取并审查 SKILL.md
curl -s "https://raw.githubusercontent.com/OWNER/REPO/main/skills/SKILL_NAME/SKILL.md"
```

## 信任层级

1. **官方 OpenClaw 技能** → 较低审查（仍需审查）
2. **高星仓库 (1000+)** → 中等审查
3. **已知作者** → 中等审查
4. **新来源/未知来源** → 最高审查
5. **请求凭证的技能** → 必须人工审批

## 注意事项

- 没有什么技能值得牺牲安全
- 有疑问就不要安装
- 高风险决策请咨询人工
- 记录审查结果供后续参考
